# Company-wise interview tracking

Use this section to organize verified company-specific interview questions, inspired by the structure of the reference repository.

**Important:** The four-week PDF does not provide company-specific questions. The topic bank is a syllabus-derived practice bank. Do not claim that a company asked a question unless you have a credible source or firsthand interview recollection.

Create one file per target company, for example:
- `company-name.md`
- Record role, level, interview round, date (if known), question wording, source/confidence, and your answer.
- Tag each question with one or more topic-bank areas.
- Separate verified questions from likely/practice questions.
