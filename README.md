## What this repository covers

LLM fundamentals, prompting and structured outputs, tool calling and agent loops, agent reliability, RAG and retrieval, memory/context/MCP, LangGraph and multi-agent systems, evaluation and observability, security and production concerns, cost/latency architecture, and AI system design.

## Four-week learning sequence

1. **Week 1 — LLM foundations and agent loop**
2. **Week 2 — RAG, memory, context engineering and MCP**
3. **Week 3 — LangGraph, multi-agent systems, evaluation and observability**
4. **Week 4 — Security, reliability, cost/latency, capstone and interview preparation**

The repository also identifies related interview areas that extend beyond the four-week roadmap. Treat those as additional preparation rather than topics explicitly covered by the source roadmap.

## Suggested workflow

For each day, study the concept, answer the matching questions aloud, implement or extend the relevant project, and record gaps in `notes/what-broke-and-why.md`. Use the company template to add questions from actual interview experiences.
